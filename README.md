# VAG Diagnostic — Sport-first iPhone Edition

Текущая версия открывается **сразу на компактной панели Sport**, рассчитанной на один экран iPhone в Bluefy. Разделы подключения, диагностики и журнала доступны через **⚙ Меню**; ничего важного не удалено.

## Начало работы
1. Открой https://3dqar.github.io/elmappaudi/ в Bluefy.
2. Вставь ELM327 BLE в OBD, включи зажигание, нажми **Подключить**.
3. На экране Sport мониторинг стартует автоматически после подключения и идентификации ЭБУ.
4. RPM и MAP опрашиваются чаще остальных данных; дополнительная задержка между быстрыми запросами убрана.
5. Остальные разделы, включая ошибки и VIN, доступны через **⚙ Меню**.

## Наддув
- ECU возвращает **абсолютное MAP** (01 0B), а BARO (01 33) на конкретной Audi пока недоступен.
- Приложение показывает **приблизительный** избыточный наддув (MAP - 101.3 кПа). Знак **≈** означает оценку. Это не точное измерение атмосферного давления.
- Для калибровки нуля: останови мотор, оставь зажигание включённым, дождись новых RPM=0 и MAP, затем нажми **◎ Калибровка 0**. Используется текущий MAP как опорная атмосфера. Калибровка действует до переподключения.
- Если автомобиль возвращает BARO, используется значение ЭБУ.
- При отрицательном избыточном давлении показание для турбо-индикатора ограничено нулём.

## Что отображается
Тахометр, наддув, скорость, MAF, нагрузка, температура впуска, температура охлаждающей жидкости и абсолютное MAP. Неподдерживаемые значения не выдумываются.

## Диагностика
Через Меню можно проверить VIN (09 02), сведения ЭБУ, поддерживаемые PID, стандартные ошибки двигателя (03/07/0A), сохранить отчёт и скопировать журнал.

**Ограничение:** доступ ко всем VAG-блокам и спецпараметрам через обычный ELM327 не гарантируется. Это не замена VCDS.

## Проверки
JavaScript успешно прошёл синтаксическую проверку, проверены обращения к HTML ID и адаптивные правила Sport. Реальная частота обновления и визуальное размещение на конкретной модели iPhone требуют проверки в Bluefy.
