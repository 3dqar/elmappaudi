# VAG Diagnostic — ELM327 BLE

Первая тестовая версия веб-приложения для iPhone и браузера Bluefy.

## Запуск бесплатно, только с iPhone
1. В GitHub открой Settings → General → Danger Zone → Change repository visibility → Public (это сделает код общедоступным).
2. В Settings → Pages выбери Deploy from a branch → main → /(root) → Save.
3. Открой https://3dqar.github.io/elmappaudi/ в Bluefy, не Safari.
4. Вставь ELM327 BLE в OBD-разъём автомобиля, включи зажигание.
5. Нажми «Найти ELM327», выбери адаптер и затем «Проверить (ATI)».
6. Если ответ не приходит, скопируй журнал и пришли его.

## Ограничения
- Экспериментальный BLE-тестер, не полноценный VCDS/ODIS.
- UUID и способ передачи различаются между ELM327 BLE клонами.
- Полный доступ к VAG блокам управления через обычный ELM327 не гарантируется.
- На первом этапе работаем только с идентификацией и настройками адаптера.
