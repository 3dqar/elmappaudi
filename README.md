# VAG Diagnostic Pro — iPhone + ELM327 BLE

Полноэкранная мобильная веб-диагностика Audi / VAG с Bluefy (Web Bluetooth). Бесплатно, без Mac и App Store.

## Как открыть
1. В браузере **Bluefy** открой https://3dqar.github.io/elmappaudi/
2. Вставь адаптер **OBDII** в OBD-разъём и включи зажигание.
3. Нажми **Подключить ELM327** и выбери **OBDII**.
4. После подключения приложение само попробует прочитать **VIN (0902)**, имя блока (090A) и Calibration ID (0904). На главной эти данные появятся в разделе «Данные из ЭБУ». При отсутствии ответа от ECU поля будут отмечены как недоступные.\n5. Нажми **Проверка ЭБУ**, дождись определения поддерживаемых PID.
6. На вкладке **Sport** нажми **Начать запись**. Для RPM заведи двигатель (автомобиль должен стоять).
7. На вкладке **Ошибки** используй **Сканировать двигатель** (режимы 03, 07, 0A — ничего не стирают).

## Что доступно
- Выделенные вкладки Главная / Sport / Ошибки / Датчики / Настройки
- BLE-профиль FFF0, запись и уведомления через FFF1, альтернативные сервисы
- Очередь команд (без параллельных ELM-запросов), таймауты, журнал
- Автоматическое чтение VIN, производителя по WMI, имени ЭБУ и Calibration ID по стандартному OBD Mode 09; точная модель и код мотора недоступны без дополнительной базы/протоколов\n- Автоопределение OBD-протокола, опрос supported PIDs
- Стандартные OBD-II датчики: RPM, скорость, MAP, BARO, MAF, охлаждение, впуск, rail, расход топлива, напряжение и т.д. (если их поддерживает ECU)
- Sport дисплей, графики, расчёт условного момента и мощности при наличии PID 62/63
- Стандартные коды P/C/B/U для OBD двигателя, локальные объяснения известных кодов, поисковые ссылки Google
- Выгрузка TXT отчёта и сохранение выбранного профиля автомобиля

## Важные ограничения
- **НЕ** полный VCDS/ODIS: обычный ELM327 не гарантирует доступ к ABS, Airbag, комфорту и остальным VAG блокам. В интерфейсе они честно помечены как недоступные.
- Коррекции форсунок, N75, заданное давление наддува и VAG measuring blocks требуют специальной поддержки конкретного ECU/протокола, которой пока нет.
- Наддув (избыточный) считается как MAP минус BARO, если поддерживаются оба PID. При отсутствии BARO показывается **абсолютное** давление MAP.
- Н·м и кВт **оценочные**, а не измеренные значения, доступны только при корректной поддержке torque PIDs.
- Сканер не удаляет ошибки и не меняет кодировки автомобиля. Использовать на стоянке.
- Декодер ошибок базовый; многофреймовые, нестандартные и VAG-специфические ответы будут улучшаться по фактическим логам.

## Если что-то не работает
Скопируй журнал из вкладки **Настройки** и отправь разработчику. Особенно полезны ответы на **0100**, **ATDP** и команды PID.
